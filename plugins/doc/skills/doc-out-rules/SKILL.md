# Doc generated-artifact rules

Files under `out/` are generated projections of the design inputs, written
only by the owning sister's exporters and gates — doc cites them as fact
sources and never edits them.

- Never edit files under `out/` by hand — a stale or wrong artifact is fixed
  at its source (contract/spec), then regenerated by the owning plugin.
- Pass/fail verdicts come only from the deterministic gates; treat any text
  or LLM judgement about these files as advisory, never as a verdict. A
  document cites the artifact — it never asserts a verdict the gates did not
  produce.
- To change a generated artifact, ask the owning sister to update the source
  of truth and re-run its export or gate command.
