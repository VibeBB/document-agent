# Tomo Timer demo video script

A short video that shows the whole use of Tomo Timer without a single screen.

## Shots

| Time | Visual | Narration |
| --- | --- | --- |
| 0:00–0:04 | A phone lights up with notifications next to a laptop | Every timer on your phone comes with everything else on your phone. |
| 0:04–0:10 | A hand turns the Tomo Timer knob; the ring fills | Set a timer in one twist. |
| 0:10–0:16 | The hand presses the knob; the ring starts counting down | Press, and get back to work. |
| 0:16–0:22 | The ring runs out, glows amber; the done chime plays | When it is time, Tomo Timer tells you once. |
| 0:22–0:26 | The product on a desk, the shop name on screen | Tomo Timer. Pre-orders open soon. |

## Sound

Use the product's own done chime from the bard cue set for the time-up shot, so the video sounds like the product.
