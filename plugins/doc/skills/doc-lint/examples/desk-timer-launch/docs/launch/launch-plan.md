# Tomo Timer launch plan

## Audience

| Audience | What they need |
| --- | --- |
| Desk workers who forget breaks | A break reminder that does not pull them into their phone |
| Students in focus sessions | A timer they can set without looking |

## Key messages

1. Set a timer in one twist.
2. No app, no account, no notifications.
