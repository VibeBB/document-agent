# Tomo Timer user manual

## In the box

- Tomo Timer
- USB-C cable

## How to use

### Set a timer

Turn the knob clockwise. Each click adds one minute, up to 90 minutes. The
light ring shows the time you picked.

### Start, pause, and stop

| You want to | Do this |
| --- | --- |
| Start | Press the knob once |
| Pause | Press the knob while it counts down |
| Stop the chime | Press the knob when it glows amber |

## Troubleshooting

| What you see | Try this |
| --- | --- |
| The ring stays dark | Check the USB-C cable and charger |
| It does not chime | The chime plays once; look for the amber glow |

## Specifications

- Size: 62 mm across, 28 mm tall
- Power: USB-C 5 V, under 0.5 W
